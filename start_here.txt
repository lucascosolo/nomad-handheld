You are helping me build Nomad, a modular pocket computer / AI assistant based on a Raspberry Pi 4 (4 GB).

Hardware:
- Raspberry Pi 4: main computer, Linux, Nomad Core, AI, tools, storage, camera, sensors
- Main microSD card goes in the Raspberry Pi
- ESP32-S3 touchscreen: display, touch, microphone, speaker, physical controls; connected to Pi over USB, likely USB CDC serial
- ESP32-S3 microSD slot is optional and should not be treated as primary storage
- RP2040-Zero: dedicated external USB HID controller for keyboard/mouse emulation
- PiSugar S Plus: battery/power management
- Future hardware: Pi camera, IMU, ToF, SDR/radio, GPS, other sensors

Design goals:
- modular monolith, not microservices
- Python
- lightweight enough for Pi 4
- hardware abstraction
- plugin/tool architecture
- internal event bus
- FastAPI HTTP/WebSocket API
- SQLite storage
- TOML config
- structured logging
- AI-provider abstraction
- mock hardware so development works without physical devices

Security:
- AI must never get unrestricted shell/device control by default
- tools declare permissions/risk
- separate request -> authorization -> execution -> result
- read-only tools may auto-run
- privileged, destructive, or external-device actions require authorization

Prefer:
- FastAPI
- Uvicorn
- Pydantic
- pytest

Avoid unnecessary infrastructure such as Redis, Celery, Kafka, Kubernetes, Docker Compose, or dependency-injection frameworks.

Important protocol design:
- Pi <-> ESP32-S3 should use an abstract transport, initially USB serial
- Pi <-> RP2040 should also use an abstract transport
- logical messages can initially be JSON but must not be permanently coupled to JSON
